# SmartCal Linker - יומן חכם 🗓️✨

אפליקציית ווב ומובייל (PWA) ההופכת כל קלט מולטימודלי (טקסט, הודעת וואטסאפ, קישור לדף אירוע, תמונת פלייר/הזמנה, מסמך PDF או הקלטה קולית) לאירוע מובנה ביומן Google, יומן Outlook Web או קובץ `.ics` בלחיצה אחת.

- **גרסה חיה (HTTPS & Mobile PWA):** [https://dymvie-alt.github.io/smartcal-linker/](https://dymvie-alt.github.io/smartcal-linker/)
- **מדריך מלא למשתמש חדש:** [USER_GUIDE.md](./USER_GUIDE.md)

## תכונות מרכזיות
- **מנוע AI מולטימודלי (`gemini-3.8-flash`):** חילוץ מדויק של כותרת, תאריכים, שעות, מיקום, מוזמנים ותקציר מתוך טקסט, URL, תמונה (`Ctrl+V`), קובץ PDF והקלטת קול.
- **ריבוי אירועים (Multi-Events Batch Mode):** זיהוי אוטומטי של מספר אירועים מקלט יחיד (טיסות הלוך-חזור, לו"ז כנס/טיול), סרגל דפדוף, שמירה סדרתית עם מעבר אוטומטי לאירוע הבא, והורדת קובץ `.ICS` מאוחד לכל האירועים יחד.
- **אירועים חוזרים (`RRULE`):** זיהוי אוטומטי של מופעים חוזרים (יומי, שבועי לפי יום בשבוע, דו-שבועי, חודשי, שנתי) עם חיווי ויזואלי בולט.
- **אבטחה ושיתוף מבוקר (Safe-by-Default):**
  - כל משתמש עובד עם מפתח Gemini API אישי וחינמי משלו השמור מקומית במכשירו בלבד (`localStorage`).
  - הפרדה מלאה בין **שיתוף נקי לחברים** (ללא חשיפת מפתח ה-API והיומנים האישיים) לבין **סנכרון אישי למכשיר שלך**.
  - אשף כניסה מהיר (Onboarding) ומדריך מובנה (`?`) למשתמש חדש.
- **הגנת מחיקה חכמה ו-Undo:** אזהרה מותנית אם אירועים טרם נשמרו ביומן ואפשרות שחזור (Undo) בלחיצה אחת.

## הרצה מקומית
הפעל את `start.cmd` או הרץ:
```bash
node server.js
```
האפליקציה תיפתח בכתובת `http://localhost:3333`.
